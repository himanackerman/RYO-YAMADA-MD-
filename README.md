## ⊹ ࣪ ˖ Tentang

**RYO YAMADA MD** adalah bot WhatsApp Multi-Device berbasis Node.js & Baileys dengan sistem **plugin modular**. Dibuat untuk hiburan, downloader, AI, sticker, game, dan otomatisasi WhatsApp — semuanya rapi dalam satu ekosistem plugin yang gampang dikembangkan.

## ✦ Keunggulan

- 🔌 **Plugin modular** — satu fitur satu file, dimuat otomatis tanpa restart

## ✦ Konfigurasi

Edit `config.js`:

```js
global.owner = [...]
global.namebot = 'RYO YAMADA MD'

global.usePairingCode = true        // true = pairing code, false = QR
global.pairingNumber = '628xxxxxxxxxx'   // nomor WhatsApp bot (format 62, tanpa + / spasi)
global.pairingCode = 'ABCD1234'     // opsional: kode custom, tepat 8 karakter huruf/angka

global.prefix = '.'                 // lihat opsi prefix di bawah
```

> [!WARNING]
> Jangan taruh token atau password di source publik ya~

**Mode login**

| Pengaturan | Hasil |
|:---|:---|
| `usePairingCode = true` | Bot menampilkan **pairing code** di console (bawaan) |
| `usePairingCode = false` | Bot menampilkan **QR** di console — scan dari **HP lain** |
| `pairingCode = 'ABCD1234'` | Pairing code memakai kode custom (kosongkan untuk kode acak) |

> [!TIP]
> Mode QR butuh paket `qrcode-terminal` (sudah ada di `package.json`).

**Opsi prefix**

| Isi `global.prefix` | Hasil |
|:---|:---|
| `'.'` | Hanya `.menu` |
| `'.!'` | `.menu` atau `!menu` (tiap karakter jadi prefix) |
| `['.', '!', 'bot ']` | Daftar prefix utuh, boleh lebih dari satu karakter |
| `''` | **Tanpa prefix** — cukup ketik `menu` |
| tidak diisi | Memakai prefix bawaan |

> [!WARNING]
> Di mode tanpa prefix, pesan yang kata pertamanya sama dengan nama command akan ikut memicu bot.

## ✦ Menjalankan Bot

```bash
npm start
```

atau langsung:

```bash
node index.js
```

Saat pertama kali jalan:

1. Bot menampilkan **pairing code** di console
2. Buka WhatsApp → **Perangkat tertaut** → **Tautkan perangkat** → **Tautkan dengan nomor telepon**
3. Masukkan kode tadi — sesi tersimpan di folder `sessions/`

## ⊹ ࣪ ˖ Struktur Plugin

Setiap fitur tersimpan rapi berdasarkan kategori di `plugins/`:

<div align="center">

`ai` `anime` `anu` `audio` `downloader` `fun` `game` `group`
`image` `info` `internet` `main` `maker` `nsfw` `owner` `panel`
`quotes` `quran` `random` `rpg` `search` `sound` `stalk`
`sticker` `store` `tools` `voice`

</div>

Contoh plugin sederhana — simpan di `plugins/<kategori>/nama.js`:

```js
const handler = async (m, { text }) => {
  await m.reply(`Input: ${text}`)
}

handler.help = ['contoh']
handler.tags = ['tools']
handler.command = ['contoh']

export default handler
```

*Plugin baru dimuat otomatis, tanpa perlu restart ✧*

<details>
<summary><b>📋 Flag plugin yang tersedia</b> <sub>(klik untuk buka)</sub></summary>

| Flag | Fungsi |
|:---|:---|
| `handler.command` | Nama command (string, array, atau regex) |
| `handler.help` / `handler.tags` | Tampil di menu |
| `handler.owner` / `handler.rowner` | Khusus owner / owner utama |
| `handler.mods` / `handler.premium` | Khusus moderator / premium |
| `handler.group` / `handler.private` | Hanya di grup / hanya di chat pribadi |
| `handler.admin` / `handler.botAdmin` | Pengirim harus admin / bot harus admin |
| `handler.limit` | Memakai limit harian |
| `handler.register` | Wajib terdaftar |
| `handler.disabled` | Matikan plugin |
| `handler.customPrefix` | Prefix khusus untuk plugin itu |
| `handler.before` / `handler.after` | Dijalankan sebelum / sesudah command lain |

</details>

## ✦ Simpan Plugin via Chat ⋅ `saveplugin`

Command: `.saveplugin` · `.sf` · `.sp` — **khusus owner** 👑

**Reply** pesan berisi kode plugin, lalu ketik:

```
.saveplugin <nama-file>
```

<table>
<tr><td>

```
.saveplugin owner
```

</td><td>➜ tersimpan di <code>plugins/owner/owner.js</code></td></tr>
<tr><td>

```
.saveplugin ai/mychat.js
```

</td><td>➜ tersimpan sesuai path custom</td></tr>
<tr><td>

```
.saveplugin ai-mychat.js
```

</td><td>➜ prefix <code>ai-</code> auto masuk folder <code>ai/</code></td></tr>
</table>

Kode dicek syntax-nya dulu sebelum disimpan — kalau error, bot balas errornya dan file **tidak** tersimpan.

## ✦ Command Owner

| Command | Fungsi |
|:---|:---|
| `.restart` · `.reboot` | Restart bot (database disimpan dulu, lalu bot kabarin saat sudah online) |
| `.setprefix <prefix>` | Ganti prefix lewat chat, `.setprefix noprefix` untuk tanpa prefix |
| `.saveplugin <nama>` | Simpan plugin dari kode yang di-reply |

> [!NOTE]
> Perubahan `.setprefix` tersimpan di memori — setelah bot restart, prefix kembali mengikuti `config.js`.

## ⊹ ࣪ ˖ Troubleshooting

<details open>
<summary><b>🩺 Masalah umum &amp; solusinya</b></summary>

| Masalah | Solusi |
|:---|:---|
| `Cannot find module` | Jalankan `npm install` |
| Error saat `npm install` / modul native | Pastikan Node **v20+**, hapus `node_modules` & `package-lock.json`, install ulang |
| Pairing code tidak bisa dipakai | Cek nomor di `config.js` (format `62…`), hapus folder `sessions/`, start ulang, langsung masukkan kodenya |
| Muncul "Koneksi terputus" terus-menerus | Lihat angka `status=` di log; hapus `sessions/` dan login ulang, pastikan bot tidak jalan di dua tempat sekaligus |
| QR tidak muncul | Pastikan `qrcode-terminal` terpasang (`npm i qrcode-terminal`) |
| Sticker / video gagal | Pasang `ffmpeg` (dan ImageMagick untuk sebagian fitur) |
| Bot tidak merespon | Cek prefix di `config.js`, cek koneksi & session WhatsApp, lihat log di terminal |
| Error tidak jelas | Cek log di terminal |

</details>
